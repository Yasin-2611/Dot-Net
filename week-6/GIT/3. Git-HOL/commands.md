# Hands-on 3 — Remote Repositories: Commands & Output

## Commands demonstrated

| # | Command | Purpose |
|---|---------|---------|
| 1 | `git clone <url>` | Clone a remote repository |
| 2 | `git remote -v` | List remote connections |
| 3 | `git remote add <name> <url>` | Add a new remote |
| 4 | `git push origin main` | Push commits to remote |
| 5 | `git pull origin main` | Fetch + merge from remote |
| 6 | `git fetch origin` | Download remote data without merging |
| 7 | `git push -u origin <branch>` | Push and track a new branch |

See [README.md](./README.md) for the full walkthrough.
