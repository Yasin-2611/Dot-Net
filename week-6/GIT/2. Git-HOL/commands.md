# Hands-on 2 — Branching & Merging: Commands & Output

## Commands demonstrated

| # | Command | Purpose |
|---|---------|---------|
| 1 | `git branch <name>` | Create a new branch |
| 2 | `git checkout <name>` | Switch to a branch |
| 3 | `git checkout -b <name>` | Create and switch in one step |
| 4 | `git branch` | List all local branches |
| 5 | `git merge <branch>` | Merge branch into current branch |
| 6 | `git branch -d <name>` | Delete a merged branch |

See [README.md](./README.md) for the full walkthrough and merge conflict resolution.
