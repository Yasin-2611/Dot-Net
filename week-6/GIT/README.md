# 9. GIT — Hands-On Solutions

Git version control hands-on exercises for the Cognizant **Digital Nurture —
.NET FSE Deepskilling** program. Each exercise documents Git commands,
expected outputs, and key concepts.

## Index

| # | Folder | Topic | Type |
|---|--------|-------|------|
| 1 | [1. Git-HOL](./1.%20Git-HOL/) | Git Basics — init, add, commit, status, log | Mandatory |
| 2 | [2. Git-HOL](./2.%20Git-HOL/) | Branching & Merging | Mandatory |
| 3 | [3. Git-HOL](./3.%20Git-HOL/) | Remote Repositories — push, pull, clone | Mandatory |
| 4 | [4. Git-HOL](./4.%20Git-HOL/) | Git Stash & Tags | Mandatory |
| 5 | [5. Git-HOL](./5.%20Git-HOL/) | Git Rebase & Cherry-pick | Mandatory |

## Format

Each exercise folder contains:
- `README.md` — Full walkthrough with commands, outputs, and explanations.
- `commands.md` — Quick-reference table of commands demonstrated.

## Tooling

- **Git** 2.x+
- Any terminal / Git Bash / PowerShell
