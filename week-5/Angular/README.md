# 10. Angular — Hands-On Solutions

Angular framework hands-on exercise for the Cognizant **Digital Nurture —
.NET FSE Deepskilling** program. Demonstrates core Angular concepts using
**TypeScript** and Angular's component-based architecture.

## Index

| # | Folder | Topic | Type |
|---|--------|-------|------|
| 1 | [Angular Hands-on](./Angular%20Hands-on/) | Components, Data Binding, Directives, Services, Routing | Mandatory |

## Tooling

- **Angular CLI** (latest)
- **TypeScript**
- **Node.js** 18+

## How to Run

```bash
npm install -g @angular/cli
cd "Angular Hands-on"
# If starting fresh: ng new angular-app --routing --style=css
ng serve --open
```

See the subfolder's `README.md` for the full walkthrough.
