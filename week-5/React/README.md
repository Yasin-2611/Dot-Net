React hands-on exercises for the Cognizant **Digital Nurture — .NET FSE
Deepskilling** program. Each exercise is a standalone single-page app using
**React 18** loaded via CDN — no build step required.

## How to Run

Each exercise folder contains an `index.html` file. Simply open it in a modern
web browser — React 18, ReactDOM, and Babel are loaded from CDN so no `npm
install` or build step is needed.

## Tooling

- **React 18** via CDN (`unpkg.com/react@18`)
- **Babel standalone** for in-browser JSX transpilation
- No Node.js or bundler required
